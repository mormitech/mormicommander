# Brief from the mormiDiskFree session (conventions to copy)

All paths under /Users/jpzwei/Code/mormidiskfree. Read the files themselves; this is a map. See also mormiview.md (and its orchestrator notes on QA, versioning and no pushing, which apply here too).

STACK: Go, Wails v2.17, vanilla JS + Vite 7, no framework. Packages only for real work. wails.json productVersion is the ONLY version source: main.go embeds wails.json for version(); CI checks tag matches.

## (1) UI

- Tokens: style.css top. :root has --bg #1b2636, --panel #223148, --text, --muted, --line, --accent #5aa9ff and wordmark colours (--wm-mormi, --wm-<app>). Dark is the default; `@media (prefers-color-scheme: light)` overrides the same tokens; color-scheme set in both. Go BackgroundColour in main.go matches --bg (27,38,54) so no white flash. Danger colour #e5484d; selection is color-mix(in srgb, var(--accent) 22%, transparent) (30% on hover). Font: 14px -apple-system, "Segoe UI", system-ui. body has user-select:none and overflow:hidden.
- Header: flex bar on --panel with bottom border; 6px-radius buttons that take an --accent border on hover. Window title "mormiDiskFree – <drive/folder name>" (WindowSetTitle) → for us "mormiCommander – <active path>".
- Context menu: one #menu div (style.css "right-click menu", main.js showMenu()/hideMenu()). Items array {label, off, run}, null = separator, muted header line names the item, opens at pointer clamped by placeNear(). Closes on mousedown outside, Escape, blur, wheel. Platform words: REVEAL = {darwin:'Show in Finder', windows:'Show in Explorer', linux:'Open containing folder'} from Go Platform() binding.
- Lists/trees: rows rendered as one innerHTML string with esc() and data-i indexes, one delegated handler per container. NO virtualization there — a commander needs real virtual scrolling for 100k-entry folders (new work).
- Keyboard: minimal there; design the full commander keymap fresh. Prefer :focus-visible outlines.
- Motion: short ease-out fades; prefers-reduced-motion turns them off. Heavy layout work goes into a Web Worker (treemap.worker.js pattern).
- Error and empty states are plain sentences in the UI, never alert().

## (2) Go side

- app.go: App struct, mu sync.Mutex, ctx from startup. Every exported method has a one-line plain-words doc comment.
- Scan: bounded semaphore (32), context cancel, "progress" event every 150 ms via runtime.EventsEmit, stays on one volume via deviceOf().
- Platform split by filename suffix: size_unix.go (//go:build !windows) / size_windows.go. internal/disk/ is UI-free so it cross-compiles and tests alone: volumes_{darwin,linux,windows,other}.go, trash_{darwin,linux,windows,other}.go.
- Trash (never permanent unless the user explicitly chooses permanent delete, e.g. Shift+F8/Shift+Del in TC): macOS osascript Finder delete (Put Back works) with the path as an argv item, never inside the script. Linux `gio trash --`, fallback `trash-put --`. Windows PowerShell Microsoft.VisualBasic FileSystem SendToRecycleBin with the path in an env var, never in the script, HideWindow:true. Return {trashed, failed} per path.
- Reveal/OpenFile: `open -R` on macOS, `explorer /select,` on Windows, `xdg-open dir` on Linux. Opening a file on Windows: rundll32 url.dll,FileProtocolHandler, NOT cmd /c start (& and ^ in paths).
- Session restore (session.go): JSON in os.UserCacheDir()/<app>, tmp+rename atomic; empty if gone; demo mode never touches it.
- Cache (cache.go): gob+gzip stdlib only, atomic CreateTemp+rename, cacheDir as var for tests.
- Mock/demo: --mock windows|linux|macos (and --demo) parsed in startFlags (main.go), mock/*.json generated by scripts/make-mock.mjs; every binding checks a.mock first. Drives screenshots and CI smoke test (xvfb-run app --mock linux).
- Tests: plain `go test`, one *_test.go per file, t.TempDir(), no test frameworks.
- Multiple windows: one window per process; About = same exe with --about (openWindow in app.go, killed in shutdown). Menus in about.go.
- window.go fitWindow: shrink to 90% of current screen and centre.

## (4) Style rules and gotchas

- Plain, concrete English, no marketing fluff, sentence case, platform-native terms (Trash vs Recycle Bin, Finder vs Explorer), ellipsis "…". Product name mormiCommander; binary/ids mormicommander. Comments explain WHY in full sentences, wrapped ~120 columns. README tone: free forever, no accounts/ads/telemetry, installed with the package manager you already use, platform status table.
- Screenshots: framed windows with title text LEFT-aligned, never centred.
- Wails v2 gotchas: Mac: &mac.Options{} must be set or the zoom button stays disabled. Linux: &linux.Options{Icon: embedded appicon.png, ProgramName: "mormicommander"}. Linux needs webkit2_41. Windows needs WebView2 runtime. One window per process. macOS Finder trash prompts once for Automation permission. Full Disk Access link: x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles. Spawned Windows processes need HideWindow.
